## INCIDENT 2 — the day-rider sold 8 lots it did not own

**The bug.** `day_rider.py`'s section-2 manage guard was `abs(net) > 1e-9 and st.get("entered")`. It
never checked `closed`, and `net` is the **shared account net**.

**The sequence.** The operator claimed the rider's 13:38 LONG at 14:26 (booked once, correctly,
+$731). At 15:53 the tournament opened `abs_veto_short`, so the account net went non-zero while
`entered` was still true for the session. The rider re-entered the manage path on a position it had
already closed, re-evaluated its **stale trail against the original entry and peak**, and every
minute booked an exit *and fired a real `MarketOrder(SELL, 2)`*:

```
15:53:21  SLD 1 @ 30117.50 + SLD 1 @ 30087.50   id=673  +$372  (phantom)
15:54:21  SLD 1 @ 30125.25 + SLD 1 @ 30095.25   id=674  +$404  (phantom)
15:55:21  SLD 2 @ 30124.75                      id=675  +$373  (phantom)
15:56:21  SLD 1 @ 30125.00 + SLD 1 @ 30095.00   id=678  +$402  (phantom)
```

**A naked 8-lot short**, while the ledger recorded +$1,551 of profit. Real cost ≈ **−$834**.

**Containment.** `day_rider=off` stopped the re-booking; `abs_veto_short=off` (execution-pathology
carve-out) stopped the position growing; `eod_flatten` took it −8 → 0; the tournament's drift halt
cleared itself once the books reconciled. The four phantom rows are flagged
`EXCLUDE:day_rider_phantom_rebook_20260813` — flagged, never deleted.

**Why nothing caught it.** Every guard was per-desk:
1. The tournament's `reconcile` runs ~every second and **did** fire (drift → halt) — but on `drift`
   the whole safety block is skipped (`max-hold` / naked-audit / re-protect / stop-breach all sit
   behind `!= "drift"`), and it has no authority over the other desk.
2. The day-rider had **no reconcile invariant at all**.
3. `multislot_core._foreign_net()` decides what is "not ours" by reading the **day-rider's own
   self-reported state file** — two books vouching for each other, no independent truth.
4. `own_flatten_verdict()` documents its own precondition — *"the caller must only reach it while its
   own state says it holds a position"* — and the caller's guard was the broken one.
5. The only cross-desk detector (`router_watch.py`'s DESK-MISMATCH) was throwing `NameError`, and the
   fix sat **un-deployed in a file while the service ran 23h-old code in memory**.

## INCIDENT 3 (quieter) — an orphan stop lived for two hours

The rider's 600pt venue stop (`orderId 49`, SELL 2 STP @ 29424.25) outlived the position it
protected: the claim closed at 14:26, the stop was still working at 18:00 against a flat account.

`eod_flatten` *tried* to cancel it and got **`Error 10147: not found`** — IBKR saying *"not yours to
cancel"* (it runs as clientId 6, the order belonged to clientId 4). **A permissions error that reads
exactly like an all-clear**, and was reported as one in this session before being caught.

This is the 08-06 shape: on that date a leftover stop fired with nothing behind it and opened a naked
short, booked six hours later as a gate trade nobody placed.

## WHAT WAS BUILT

### Safety
| component | what it owns |
|---|---|
| `src/gazbot7/deskrecon.py` | the invariant `venue == tournament + rider`, pure and testable |
| `scripts/desk_reconcile.py` + timer (**30s**) | reads IBKR **read-only** (clientId 8), confirms a breach on TWO independent reads, then stops **BOTH** desks (kill file + bench all gates + rider off) and pages. **Never re-arms** — release is a human act. Also runs the **inverse audit**: any working stop that would OPEN rather than reduce. |
| `day_rider.venue_first_ok()` | gates ENTRY / TRAIL / MANUAL_CLAIM / OPERATOR_SELL on the invariant. **NOT the 20:40 hard flat** — refusing to flatten because the books disagree turns a bookkeeping fault into an overnight position, which is strictly worse. A test pins that exemption. |
| `day_rider.cancel_own_stops()` | takes the venue stop down on all five close paths. **clientId-filtered** — it must never cancel the tournament's per-slot stops; that is the safety property, and it is tested. |

**★ On a netted shared account, "read the venue" is not enough.** IBKR nets both desks into ONE
number, so a desk **cannot** read its own position from it. Venue-first therefore means: *nobody may
act unless the whole account reconciles against every desk's claim.* An unaccounted lot means some
book is lying and you do not know which.

## LESSONS (each one cost something today)

1. **Editing a file is not deploying it.** The `router_watch` fix sat un-deployed for 2.5h while the
   service ran 23h-old code. After editing anything a long-running service imports: restart it and
   **grep the log for the old symptom**.
2. **A permissions error can read as an all-clear.** `Error 10147` meant "not yours", not "gone".
3. **A right number beside a wrong one is worse than either alone.** The header was correct while the
   blotter and the curve carried $1,551 of phantoms — and nothing said which to believe.
4. **Silent type mismatches return zero rows, not errors.** `exit_ts` is an integer epoch; comparing
   it to an ISO string in SQLite silently matches nothing.
5. **Check whether a thing already exists before building it.** The durable event watcher had existed
   since 08-11; a duplicate was written and the live unit file briefly overwritten.
6. **A detector that halts must not stop checking.** Gating the safety block behind `!= "drift"`
   means the alarm disables the fire brigade.
