**Why:** the market supports both directions, just at different moments — so a genuinely good gate mechanism earns on both sides. Saying "rgv_long is no good, rgv_short is great" (or running thrust_short/grind_long single-sided live) judges *direction* when the real question is whether the long side needs *different thresholds* (ER band, absorption floor, extension/turn, ATR floor) than the short. Long and short are different profiles; the same numbers flipped (an "exactly inverse gate") is almost never the right tuning for both. When one side looks dead, the first suspect is mirror-tuning, not the direction.
