**★ OPS LESSON — reboot sequencing (2026-07-10, learned the hard way — a ~20min 5s-feed outage):** adding a sub / fixing the 2026-07-03-class 5s-stale-while-ticks-live break needs **`docker restart alphabot-gateway`** (real IBC re-login ~90s), NOT `systemctl` (broker reconnects in ~10s → IB Gateway never reset → reqRealTimeBars farm stays stuck). **BUT the killer detail: after the docker restart, WAIT until the broker is *sustainedly* HEALTHY (full IBC login — port-open at ~30s is NOT enough) BEFORE bouncing `alphabot-market-data`, and bounce it EXACTLY ONCE.** Stacking service restarts while IBC is mid-login RE-STICKS the reqRealTimeBars farm (the MD daemon subscribes before its clientId-14 connection is up; the "retry on reconnect" path fires for the trade-tick recorder but NOT reliably for reqRealTimeBars). The clean sequence: docker restart gateway → poll broker /health until HEALTHY + settle 30s → single MD bounce → poll for fresh 5s bars.
