scope doc and `MGC_FEE_RT` — all three corrected.

**The coil bouncer is breakeven, not refuted.** Not a shadow arm on that evidence; not a closed lead

re-derive it from the mechanism (how many times do you cross?) before letting it refute anything.**

## LESSONS (each one cost time today)

1. **A cost constant refutes things.** See the ruling above. Re-derive from the mechanism.
2. **A slate is assembled from helpers, so the file you edited may not be the one that runs.** I
   applied the trim filter to `_stop_width_ab()`'s return instead of `default_slate()`'s and cut 10
   arms instead of 27. **The assertion caught it; reading the diff did not.** Same family as the
   `slot_strategy.py:116` vs `:161` trap.
3. **A control is supposed to lose.** Classify control / paired / factorial / slow-firing BEFORE
   ranking anything on P&L, and rank only what is left.
4. **`q.index` was `datetime64[ms]`**, so `.view("int64") // 10**6` converted to ms twice —
   1784163780000 became 1784163, `searchsorted` put every fire past the end of the tape, and the
   result was an empty book that **reads exactly like "the gate never fired"**.
5. **Thin n is not evidence.** The Open Rider fires ~once a day. Cut it on a reason, never on n.
