## 1. L2 BOOK — capture moved into V7

The 10-level book had been captured since 07-15 by `alphabot-depth-capture` **inside the retired V5
tree**. Two failures came from that placement: I told the operator we did not persist the book at all
(4.2M MNQ snapshots existed), and **nothing swept it**, so a silent death would have stopped the history
every L2 study depends on.

Now `gazbot7-depth-capture.service`, V7 data dir, in `gazbot7.slice`, watched by `sweep.py` **twice** —
the unit AND a data-freshness check, because an active timer is not proof of capture.

- `FLUSH_S` 5.0 → 1.0. Live reads were up to 5s stale *by design*; now ~0.9s.
- **MNQ + MGC only.** IBKR caps market depth at **THREE** subscriptions account-wide; a fourth returns
  `Error 309`, which is why M2K silently stopped on 07-29.
- Retention 20 → 28 days.

### The arithmetic I got wrong
`cl_sims.build_ctx` excluded the book with the stated reason "~86 contracts visible vs ~2,664/min flow,
6x too thin". Measured: **162 contracts vs ~170/min** — the book is ~57 SECONDS of flow. It also compared
a *stock* of resting liquidity against a *flow rate*. Conclusion inverted.

### And the correction to that correction
I then called `capture.db`'s `book` table "the weaker copy of depth.db" and cut it to 5 days. Also wrong:
it is shallower (levels 0-4 vs 10) but **6x finer in time** — 87,142 distinct timestamps/hour, one every
**41 ms**, event-driven, against depth.db's 250 ms sample. Fleeting quotes live *between* 250 ms samples
and are the actual spoofing tell. Reverted, and added to the permanent archive, which it had been
**missing from entirely**.

## 5. ★★ THE INCIDENTS

### MD_STREAM is multi-symbol — the expensive one

`md` publishes every captured symbol on ONE stream, correctly tagged. **Three consumers folded every bar
into a single MNQ deque without checking the tag.** Harmless for the desk's whole life because md only
ever captured MNQ. **Adding MGC at 17:30 armed it**: gold (~3,300) interleaved with MNQ (~29,800), and
true range across that jump is astronomic.

**`entry_atr` read 1848.16 against a true 15.11 — 122x.** The desk opened two `abs_veto_short` lots with
stops **1,848 points** away instead of ~15, targets unreachable. Closed by `MAX_HOLD` at exactly 2 hours
for **-$255.50** — 3.7x a normal loss, because the position had no working protection for two hours.
Every gate threshold is ATR-relative, so entries and exits were corrupted at once, and the shadow desk
ate the same features from 17:30 (rows in that window are suspect).

**A CONFIG change in one file armed a latent bug in three others.** No test of the changed file could
have caught it. Every `capture.db` reader was already safe because **SQL forces you to name the symbol**;
only the message bus left it optional, and all three consumers forgot.

Fixed in all three (including the retired `strategy.py`, so a revert cannot resurrect it) and pinned by
`tests/test_md_symbol_filter.py`, which also asserts the guard precedes the fold.

### Things that failed safe and would therefore have hidden

- Router `PINNED` covering the full roster → 411 ticks logging "no change" while doing nothing
- The tape-mirror floor treating a **Saturday** as a missing archive → prune disabled forever
- `router_watch` emitting BREAK on **unmeasurable** ATR → two false breaks every session reopen
  ("I cannot measure volatility" was being read as "volatility is fine")

### Method errors worth not repeating

- **Config epochs.** Applying today's exit spec to trades that predated it produced a confident
  **+$2,477** for 2.0x stops. Pure artefact, caught only because the harness reports `k=1.0` as a
  live-reproduction check — it was 56% off.
- **`exit_scalp` couples target to stop width** (`target_r * (stop_atr_mult * atr)`), so testing a wider
  stop silently doubles the target too.
- **Match tolerance is an assumption.** A 120s pairing window manufactured "36pt of slippage" out of
  trades 66-112s apart. At 5s the real figure is 2.25pt.
- **Strip-best before quoting any live record.** +$1,103 became -$524 on one trade.
- **`protection.held` says a stop EXISTS, not that it is SANE.** Check the distance.
